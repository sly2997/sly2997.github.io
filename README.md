# igbafesylvia.github.io

Personal portfolio site for Sylvia Igbafe.

## Putting it online (GitHub Pages, free)

1. On GitHub, create a **new public repository** named exactly:

       sly2997.github.io

   The name must match your username exactly, or the site will not appear at the
   short address.

2. Upload the contents of this folder into the top level of that repository:

       index.html
       scene-lab.png
       scene-desk.png
       scene-field.png

   Use **Add file > Upload files** on the repository page and drag all four in.
   `index.html` must sit at the top level, not inside a folder.

3. Go to **Settings > Pages**. Under *Source*, choose **Deploy from a branch**,
   pick branch `main` and folder `/ (root)`. Save.

4. Wait two or three minutes, then open:

       https://sly2997.github.io

   That is the address to put on your CV and LinkedIn.

## The contact form

Already switched on. Your Web3Forms access key is in `index.html`, so every
submission arrives in your Gmail inbox at igbafesylvia@gmail.com. The free tier
covers 250 messages a month, far more than a portfolio receives.

Send yourself a test message once the site is live, and check the spam folder
for the first one.

If a send ever fails, the form falls back to copying the message to the
visitor's clipboard and showing your email address, so nobody presses a dead
button.

The form also has a hidden honeypot field that catches most spam bots.
